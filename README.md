# Budget · Devlin

Appli de suivi de budget (PWA) installée sur l'écran d'accueil du téléphone.

- **L'appli** : `index.html`, `sw.js` (fonctionnement hors ligne), `manifest.json`, icônes. Publiée par GitHub Pages.
- **Les données** : le Google Sheet « Budget_Global_Devlin ». L'appli lit et écrit dedans via le script Apps Script attaché au Sheet (copie du code dans `apps-script/`).
- **Version** : affichée en bas des Réglages de l'appli.

Pour récupérer l'appli à ton nom, suis la procédure « Récupérer ton appli Budget » envoyée par Théo.

Une fois à ton nom, l'appli est à toi : elle ne reçoit plus les nouveautés de Théo et reste telle quelle. Ton adresse : `https://TON-PSEUDO.github.io/` suivi du nom de ce dépôt. Les fichiers `moteur.js` et `sauvegarde.js` servent à un mode d'essai désactivé : ne les supprime pas, ils ne gênent rien.
