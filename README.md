# Budget · Devlin

Appli de suivi de budget (PWA) installée sur l'écran d'accueil du téléphone.

- **L'appli** : `index.html`, `sw.js` (fonctionnement hors ligne), `manifest.json`, icônes. Publiée par GitHub Pages.
- **Les données** : le Google Sheet « Budget_Global_Devlin ». L'appli lit et écrit dedans via le script Apps Script attaché au Sheet (copie du code dans `apps-script/`).
- **Version** : affichée en bas des Réglages de l'appli.

Pour transférer l'appli à son propriétaire, suivre la fiche « Transférer l'appli Budget ».
